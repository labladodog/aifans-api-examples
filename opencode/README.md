# OpenCode

1. Set your key: `export AIFANS_API_KEY="YOUR_API_KEY"` (PowerShell: `$env:AIFANS_API_KEY = "YOUR_API_KEY"`).
2. Copy [`opencode.json`](opencode.json) to your project root (or `~/.config/opencode/opencode.json`).
3. Run `opencode` and pick a model with `/models`.

Full guide: https://platform.aifans.fan/guides/opencode-aider
