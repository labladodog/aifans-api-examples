# Claude Code

1. Copy [`settings.json`](settings.json) to `~/.claude/settings.json`
   (Windows: `%USERPROFILE%\.claude\settings.json`) and put your key in `ANTHROPIC_AUTH_TOKEN`.
2. Start Claude Code: `claude`

Want it cheaper? Use `deepseek-v4.1-flash` for every model line instead of `deepseek-v4-pro`.
Run `/compact` now and then: a shorter context costs less and stays under the per-minute limits.

Full guide: https://platform.aifans.fan/guides/claude-code
